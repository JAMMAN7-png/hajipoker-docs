Want to play poker with just your friends? HajiPoker lets you create **private tables** that are password-protected, so only people you invite can join.

## What Is a Private Table?

A private table works exactly like a regular poker table, but with one key difference: it requires a **password** to join. Private tables don't appear in the public lobby, so only players who have the password can find and sit at your table.

## How to Create a Private Table

1. Go to the **Lobby**
2. Click the **Create Table** button
3. Fill in the table settings (see below)
4. Enable the **Private Table** option
5. Set a **password** for the table
6. Click **Create**
7. Share the password with the friends you want to invite

## Table Settings

When creating a table, you can customize the following settings:

### Game Type
Choose from:
- **Texas Hold'em** — 2 hole cards, the classic game
- **Omaha 4-Card** — 4 hole cards, more action
- **Omaha 5-Card** — 5 hole cards, maximum action

### Blinds
Set the small blind and big blind amounts. The default is **25/50** (small blind of 25 chips, big blind of 50 chips). Higher blinds mean bigger pots and faster action.

### Buy-in Range
Set the **minimum** and **maximum buy-in** amounts for the table. This controls how many chips players can bring:
- A lower minimum makes the table accessible to players with smaller bankrolls
- A higher maximum allows for deeper-stacked play

### Player Count
Choose how many seats your table has, from **2 to 9 players**:
- **2 players** — A heads-up game, just you and one friend
- **3–6 players** — A short-handed game with faster action
- **7–9 players** — A full ring game for larger groups

### Password
Enter a password that your friends will need to type in order to join the table. Share this privately with the people you want to play with.

<Callout type="warn">
Only share your table password with people you want to play with. Anyone who has the password can join your private table.
</Callout>

## Joining a Private Table

If a friend has created a private table and shared the password with you:

1. Ask your friend for the **table password**
2. Navigate to the lobby
3. Look for the option to **Join Private Table** or enter the table password
4. Enter the password
5. Choose your buy-in amount
6. Take your seat!

## Private Table Rules

Private tables follow the same rules as regular tables:

- Minimum of **2 players** required to start a hand
- Maximum of **9 players** per table
- The same poker rules apply for the selected game type
- Blinds rotate normally
- Rake is collected the same way as on public tables

## Tips for Hosting a Private Game

- **Agree on stakes beforehand** — Make sure everyone is comfortable with the blind level and buy-in range
- **Set a reasonable buy-in range** — A wider range lets players with different budgets join comfortably
- **Choose the right table size** — If you have 4 friends coming, a 5 or 6-seat table is ideal (leaves room for a late joiner)
- **Share the password securely** — Send it through a private message, not in a public chat
- **Pick a game type everyone knows** — If some players are new, stick with Texas Hold'em

## Common Questions

**Q: Can I change the table settings after creation?**
No, table settings are fixed once the table is created. If you want different settings, create a new table.

**Q: Is there a limit to how many private tables I can create?**
There's no strict limit, but only one table per player can be active at a time.

**Q: Do private tables appear in the public lobby?**
No. Private tables are hidden from the public lobby. Only players with the password can join.

**Q: Is the rake different for private tables?**
No, the same rake structure applies to both public and private tables.
